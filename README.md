# 山间 · 静心空间

一个可以走进去的 3D 静心空间：在山间小亭里走一走、坐一会儿，做 108 次呼吸，拨一拨数息珠，或者只是听着风声发呆。

**在线访问：** https://kevinshan555.github.io/shanjian/

## 这是什么

受“线上寺庙”现象启发，但做成了一个**去宗教化**的静心/解压体验：

- 3D 山间小亭，可自由走动、环顾、坐下
- 108 次呼吸引导（吸气 / 停一停 / 呼气）
- 数息珠：一轮 108 颗
- 木鱼：传统打击乐器音效，仅用于节奏放松
- 环境声由 Web Audio 实时合成：风声、鸟鸣、溪流、远处钟声
- 无注册、无登录、无数据采集、无后端

## 合规说明

本网站为静心与放松体验，**不提供宗教仪式、祈福、法事、供奉、捐赠等任何宗教服务，也不涉及宗教信息传播**。亭中其他身影是场景的一部分，并非真实在线用户。本站为纯静态页面，不在服务器保存任何个人信息。

本网站不构成医疗或心理治疗建议。如果你正经历严重的焦虑、抑郁或睡眠问题，请寻求专业帮助。

## 技术

- Three.js r150（本地打包，不依赖 CDN）
- 原生 HTML / CSS / JavaScript，无构建步骤
- Web Audio API 实时合成全部声音，不加载音频文件
- 适配桌面与手机（虚拟摇杆、触屏拖动、双指缩放）
